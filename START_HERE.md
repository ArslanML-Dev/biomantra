# Start here

1. **Install:**
   - Python 3.11, Node.js 20 LTS and Git.
   - Android Studio (needed from Day 2) and the VS Code terminal.
   - Claude Code.
2. **Make the folder:** create a folder `biomantra`, put these files in it, and keep the same layout:
   ```
   biomantra/CLAUDE.md
   biomantra/docs/SPEC.md
   biomantra/docs/TASKS.md
   biomantra/docs/progress.md
   ```
3. **Get the keys:**
   - Get a free OpenWeather API key (new keys can take 1–2 hours to activate).
   - Find your campus latitude/longitude in Google Maps (right-click → copy the coordinates).
4. **Open Claude Code:** open a terminal in `biomantra/` and run `claude`.
5. **First message:**
   > Read CLAUDE.md, docs/SPEC.md and docs/TASKS.md. Summarise the plan in 10 lines, then start D1-T1.
6. **After each task:** check the output it shows, then say "next task". If something breaks, paste the error back here.
