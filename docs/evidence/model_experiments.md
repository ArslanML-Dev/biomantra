# Forecast model experiments

Generated by `backend/scripts/train_forecast.py` (real numbers, re-run to reproduce).
Data: Open-Meteo hourly PM2.5 + weather, 37,008 rows shared by every run; split 70/15/15 in time order; test period 2026-03-08 → 2026-10-25.

**Targets.** `t24` = PM2.5 at exactly t+24 h (the original model). `mean24` = mean PM2.5 over t+1…t+24 h (new; matches the CPCB 24-hour averaging).

**Next-24 h weather features (new).** Mean temperature, humidity, wind speed, wind direction (sin/cos) and total rain over t+1…t+24 h. In training these are the *actual* observed values, used as a stand-in for a weather forecast; at live inference `/forecast` takes them from the Open-Meteo weather forecast. Real forecasts have errors, so scores with these features are an **optimistic upper bound**. No future PM2.5 is ever used as a feature.

**Selection rule (fixed before running).** Use target `mean24`; pick the feature set + model with the lowest **validation** MAE. Test scores are only reported.

MAE values for `t24` and `mean24` measure different targets, so compare them within a target. Category metrics compare the forecast category with the true category of the same target.

## Interpretation (written from the table above)

- **Old vs new, same question ("which CPCB category will tomorrow be?").** The original model (LightGBM, t24, past only) reached category accuracy 0.399, macro-F1 0.335 and Poor+ recall 0.681. The chosen model (LightGBM, mean24, past + next-24 h weather) reaches 0.559, 0.478 and 0.771. Note that the "true" category also changes: it's the category of the 24-hour mean (which is how CPCB defines the bands) rather than of a single hour.
- **The 24-hour-mean target is the biggest win.** Even the persistence baseline improves (test MAE 33.66 → 24.33), because a 24-hour mean is smoother and easier to predict than one hour. That's why MAE must only be compared within the same target.
- **Next-24 h weather helps LightGBM but not linear regression.** With the mean24 target, LightGBM's test MAE goes 19.75 → 18.07 and its validation MAE 15.04 → 12.91. Linear regression stays at 19.50 → 19.53 on test, though its validation MAE improves (15.18 → 14.42). On the old t24 target, LightGBM also improves (30.02 → 28.03).
- **LightGBM now clearly beats both baselines on its target:** test MAE 18.07 vs linear 19.53 and persistence 24.33. With the old setup it only tied linear regression.
- **Honest caveat:** the next-24 h weather features use the *actual* weather in training and test. The live app uses the Open-Meteo weather forecast, which is less accurate, so live performance will be between the "past only" and the "past + weather" rows. The old plots and metrics are kept in `docs/evidence/model_v1/`.
